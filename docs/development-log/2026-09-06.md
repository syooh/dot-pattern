# 4. MySQL PATH 설정

PowerShell에서 처음 `mysql --version` 명령을 실행했을 때 MySQL 명령어를 찾지 못하는 문제가 발생했다.

확인 결과 MySQL Server는 정상적으로 설치되어 있었지만 `mysql.exe`가 Windows PATH에 등록되어 있지 않았다.

실제 실행 파일 위치를 확인했다.

```text
C:\Program Files\MySQL\MySQL Server 9.7\bin\mysql.exe
```

해당 경로를 Windows PATH에 추가한 후 새 PowerShell에서 다음 명령을 실행하여 정상 동작을 확인했다.

```powershell
mysql --version
```

# 9. Django와 MySQL 연결 설정

다음 Django 설정 파일을 수정했다.

```text
backend/django/config/settings.py
```

기존 Django 기본 데이터베이스인 SQLite 설정을 제거하고 MySQL을 사용하도록 변경했다.

주요 설정:

```python
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.mysql",
        "NAME": "dot_pattern_db",
        "HOST": "localhost",
        "PORT": "3306",
        "USER": "root",
        "PASSWORD": "본인의 MySQL 비밀번호",
    }
}
```

이를 통해 Django가 로컬 MySQL Server의 `dot_pattern_db` 데이터베이스를 사용하도록 설정했다.

# 10. Django Migration을 통한 연결 테스트

Django 프로젝트 디렉터리에서 다음 명령을 실행했다.

```powershell
python manage.py migrate
```

Migration이 정상적으로 실행되었으며 Django의 기본 테이블이 MySQL 데이터베이스에 생성되는 것을 확인했다.

이를 통해 다음 연결이 정상적으로 동작함을 확인했다.

```text
Django
   ↓
mysqlclient
   ↓
MySQL Server 9.7.1
   ↓
dot_pattern_db
```
