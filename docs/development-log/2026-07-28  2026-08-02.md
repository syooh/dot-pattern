**Dot Pattern Editor**

기간 : 2026-07-28 ~ 2026-08-02

# 개발 목표

도안 편집기의 핵심 기능을 완성하고, 이미지를 도트 도안으로 변환하여 React Editor와 연결하는 기능을 구현한다.

---

# 작업 내용

## 1. Fill Tool 구현

### 구현 내용

- Flood Fill 알고리즘 구현
- 동일한 색상을 기준으로 인접 영역을 한 번에 채우는 기능 추가
- Undo / Redo와 연동

### 결과

- Paint Bucket 기능 정상 동작
- 기존 브러시와 동일한 방식으로 히스토리 저장

- 삭제

### 결과

도안의 특정 영역을 자유롭게 편집할 수 있도록 개선하였다.

## 6. FastAPI 연동

### 구현 내용

이미지를 업로드하여 도안을 생성하는 API를 구현하였다.

```
React

↓

FastAPI

↓

이미지 분석

↓

PatternData(JSON)

↓

React Canvas
```

### API

```
POST /generate
```

### 기능

- 이미지 업로드
- Width 지정
- Height 자동 계산
- Color Count 지정
- PatternData 반환

---

## 7. 이미지 Import 기능 구현

### 구현 내용

React에서 이미지를 선택하여 FastAPI로 업로드하고 생성된 PatternData를 Canvas에 적용하도록 구현하였다.

### UI

Palette 아래에 Import Panel을 추가하였다.

구성

- 이미지 선택
- Width
- Height
- Color Count
- Generate 버튼

### 결과

이미지를 즉시 도트 도안으로 변환하여 편집할 수 있게 되었다.

---

## 8. Backend 개선

### calculate_size()

이미지 비율 유지 기능 개선

지원 방식

- Width 기준
- Height 기준
- Width + Height 직접 지정

또한

- Height = 0
- Height < 0
- None

예외 처리를 추가하였다.

---

## 9. JSON Export 구조 개선

- palette
- pixels

White / Black 기본 색상을 항상 유지할 수 있는 구조를 설계하였다.

# 회고

이번 개발 기간 동안 프로젝트는 단순한 도안 편집기에서 이미지를 도트 도안으로 변환하고 편집할 수 있는 수준까지 발전하였다.

Selection 기능과 이미지 Import 기능이 추가되면서 실제 사용 가능한 형태에 가까워졌으며, 현재는 출력(Export) 기능을 마무리하는 단계에 진입하였다.

다음 개발에서는 PNG 출력 품질 향상과 문서화를 진행하여 v1.0 릴리즈를 목표로 한다.
