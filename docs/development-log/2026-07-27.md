# ✅ 작업 내용

## 1. Paste Preview 개선

* Paste Preview가 정상적으로 출력되도록 수정
* Paste Mode에서 Preview가 마우스를 따라다니도록 구현
* Preview Layer를 Canvas Renderer에 연결
* Paste Preview가 다른 Layer와 충돌하지 않도록 구조 개선

---

## 2. Move Tool 추가

### Tool 추가

* Move Tool(Type: `"move"`) 추가
* Toolbar에 Move Tool 버튼 추가
* ToolType에 `"move"` 등록

---

### Canvas Event 수정

Move Tool 전용 이벤트 추가

* Selection Drag 시작
* Drag 좌표 저장
* Drag 종료 이벤트 추가
* Move 완료 이벤트(onMoveSelection) 생성

---

### Selection Preview 구현

Selection에 다음 상태 추가

* offsetX
* offsetY
* isDragging

SelectionLayer 수정

* offset을 이용하여 선택 영역 Preview 출력
* 선택 영역이 마우스를 따라다니도록 구현

---

---

# 📌 느낀 점

Move Tool은 프로젝트에서 가장 복잡한 기능 중 하나였지만, Event → Editor → Hook → Engine 구조를 유지하면서 구현하여 코드의 일관성을 지킬 수 있었다.

Selection 기능이 거의 완성 단계에 도달했다.
