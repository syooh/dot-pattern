## 3. JWT 기반 인증 기능 구현

Django REST Framework Simple JWT를 사용하여 사용자 인증 기능을 구성했다.

### 구현 기능

* 회원가입
* 로그인
* Access Token 발급
* Refresh Token 발급
* Access Token 갱신
* 로그인 사용자 정보 확인
* 로그아웃

### API

```text
POST /api/auth/register/
POST /api/auth/login/
POST /api/auth/token/refresh/
GET  /api/auth/me/
```

### Frontend

React에서 인증 상태를 관리하기 위한 `AuthContext`를 구성했다.

인증 상태:

```text
로그인 전
    ↓
로그인
    ↓
JWT 저장
    ↓
사용자 정보 확인
    ↓
로그인 상태 유지
```

로그아웃 시 저장된 인증 정보를 제거하도록 구성했다.

### 테스트 결과

* 회원가입 정상 동작
* 로그인 정상 동작
* 로그아웃 정상 동작
* 인증이 필요한 `/auth/me/` API 정상 동작

## 4. Pattern CRUD API 구현

Django에 Pattern 모델과 REST API를 구현했다.

### Pattern 주요 데이터

```text
owner
title
width
height
is_public
pattern_data
created_at
updated_at
```

Pattern 데이터는 JSON 형태로 저장하도록 구성했다.

### API

```text
POST   /api/patterns/
GET    /api/patterns/
GET    /api/patterns/{id}/
PATCH  /api/patterns/{id}/
DELETE /api/patterns/{id}/
```

### 권한

Pattern은 현재 로그인한 사용자 자신의 데이터만 조회 및 수정할 수 있도록 구성했다.

Pattern의 `owner`는 클라이언트에서 전달받지 않고 Django의 `request.user`를 사용하도록 구현했다.

### 테스트 결과

* Pattern 생성 성공
* Pattern 목록 조회 성공
* Pattern 상세 조회 성공
* Pattern 수정 성공
* Pattern 데이터 수정 성공
* Pattern 삭제 성공
* 삭제된 Pattern 접근 시 404 확인

## 8. Edit / View 모드 하이라이트 이동 동작 개선

Edit 모드에서 `이전 / 다음` 버튼을 통해 현재 행 하이라이트가 이동하지 않도록 수정했다.

### Edit 모드

```text
이전 / 다음 버튼
→ 비활성화
```

### View 모드

```text
이전 / 다음 버튼
→ 활성화
```

View 모드에서는 기존의 행 하이라이트 이동 기능을 그대로 사용할 수 있도록 유지했다.

이를 통해 Edit 모드와 View 모드의 역할을 명확하게 구분했다.
