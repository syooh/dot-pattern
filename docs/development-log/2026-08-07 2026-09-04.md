# 43. Stitch 기능 보류

Stitch Pattern 기능은 현재 Editor 안정화를 위해 잠시 보류한다.

검토한 문제:

- 원본 Pixel 데이터를 유지해야 함
- 두 개의 세로 Pixel을 하나의 Stitch처럼 표현하는 방식 필요
- 실제 PatternData를 물리적으로 합치면 원본 데이터가 손상될 수 있음
- 서로 다른 색상의 Pixel을 하나의 Stitch로 표현할 경우 색상 처리 문제가 발생할 수 있음

따라서 현재는 원본 PatternData를 유지하고
Stitch는 별도의 View Layer에서 시각적으로 표현하는 방향을 고려한다.

개발 방향은 다음과 같다.

```text
현재
│
├── React + TypeScript
├── Canvas Editor
├── Pattern Editing
├── View Mode
├── Current Row
├── PNG / JSON Export
│
▼
Django Backend
│
├── Django REST Framework
├── MySQL
├── JWT
├── User
├── Pattern CRUD
└── Permission
│
▼
서비스 형태로 확장
│
├── 회원가입 / 로그인
├── 개인 Pattern 관리
├── Pattern 저장
├── Pattern 불러오기
├── Pattern 공개 / 비공개
└── 다른 사용자의 Pattern View
